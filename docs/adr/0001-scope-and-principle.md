# ADR 0001: Scope and founding principle

Status: Accepted (2026-10-04)

INTERPLANE is a neutral interoperability protocol between AI models (the intelligence plane) and
agent runtimes (the execution plane). Models express intent; runtimes retain authority; INTERPLANE
defines the boundary. It is not an agent framework, not an MCP replacement, not a runtime policy
system and not a serving engine. Core depends on no host project and no serving engine.

Reference integrations: AIEN (Rust) and Odysseus (Python) as runtimes; Qwen3.5 as the first
qualified model dialect; Ajax when an official artifact exists.

Decided by the project owner on 2026-10-04 from the live audit in `CURRENT_STATE.md`.
